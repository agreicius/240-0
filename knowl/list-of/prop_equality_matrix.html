Proposition 1.1.11. Equality of matrices.

The matrix \([a_{i,j}]_{m\times n}\) is equal to the matrix \([b_{i,j}]_{m'\times n'}\) if and only if
  1. \(m=m'\) and \(n=n'\text{;}\)
    🔗
    🔗
  2. \(a_{i,j}=b_{i,j}\) for all \(i\in \{1,2,\dots, m\}\) and \(j\in \{1,2,\dots, n\}\text{.}\)
    🔗
    🔗
In other words, two matrices are equal if and only if they have the same dimensions and the same entries in each position.
🔗
🔗

Proof.
Unpacking the the notational conventions, we have \([a_{i,j}]_{m\times n}=(a_{(i,j)})_{(i,j)\in I}\text{,}\) where \(I=\{1,2,\dots, m\}\times \{1,2,\dots, n\}\) and \([b_{i,j}]_{m'\times n'}=(b_{(i,j)})_{(i,j)\in J}\text{,}\) where \(J=\{1,2,\dots, m'\}\times \{1,2,\dots, n'\}\text{.}\) By Definition 1.1.9, the two matrices are equal if and only if \(I=J\) and \(a_{(i,j)}=b_{(i,j)}\) for all \((i,j)\in I\text{.}\) The first condition is equivalent to \(m=m'\) and \(n=n'\text{,}\) and the second condition is equivalent to \(a_{i,j}=b_{i,j}\) for all \(i\in \{1,2,\dots, m\}\) and \(j\in \{1,2,\dots, n\}\text{.}\)
