Definition 1.1.1. Real-valued tuple.

Let \(I\) be a nonempty set. A real-valued tuple indexed by \(I\) (or \(I\)-tuple of real numbers) is a rule that assigns to each index \(i\in I\) an element \(a_i\in \R\text{,}\) and is denoted \((a_i)_{i\in I}\text{.}\)
🔗
Given an \(I\)-tuple \((a_i)_{i\in I}\text{,}\) we call \(I\) the index set, and for each index \(i\in I\text{,}\) we call \(a_i\) the \(i\)-th component (or coordinate, or entry, or term) of \((a_i)_{i\in I}\text{.}\) We call \(\{a_i\mid i\in I\}\) the set of values of the tuple \((a_i)_{i\in I}\text{.}\)
🔗
The set of all real-valued \(I\)-tuples is denoted \(\R^I\text{:}\)i.e.,
\begin{equation*} \R^I=\{(a_i)_{i\in I}\mid a_i\in \R \text{ for all } i\in I\}\text{.} \end{equation*}
