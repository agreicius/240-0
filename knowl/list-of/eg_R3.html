Example 1.1.5. Index set for \(\R^3\).

The set \(\R^3\) of all triples can be expressed in our new language as \(\R^I\) for a particular index set \(I\text{.}\) Explain.
🔗
Solution.
Using the conventional subscript notation \((a_1,a_2,a_3)\text{,}\) we see that an element of \(\R^3\) is defined by assigning a value \(a_1\) for its first component, a value \(a_2\) for its second component, and a value \(a_3\) for its third component. Thus our index set here can be taken to be \(I=\{1,2,3\}\text{,}\) and we have
\begin{equation*} \R^3=\R^I=\R^{\{1,2,3\}}\text{.} \end{equation*}
