Exercise 16.

Show that it is not the case that every element of \(\R^\infty\) can be written as a linear combination of the set \(S=\{\bolde_1,\bolde_2,\bolde_3,\dots\}\) of indicator vectors of \(\R^\infty\text{.}\) In more detail, provide an explicit infinite sequence \(s=(s_i)_{i=1}^\infty\) that is not a linear combination of \(S\text{.}\)
🔗
Hint.
Show that any linear combination of \(S\) is of the form \(\sum_{i=1}^n c_i\bolde_i\) for some positive integer \(n\) and scalars \(c_1,c_2,\dots, c_n\) (some of which could be zero). Expand out this linear combination as an infinite sequence and provide an infinite sequence that doesn’t look like this!
🔗
🔗
Solution.
The underlying issue here is that by definition a linear combination of any set of vectors is a finite sum of scalar multiples of vectors from that set. In the present case, that means an arbitrary linear combination of \(S\) is of the form
\begin{equation*} s=d_{i_1}\bolde_{i_1}+d_{i_2}\bolde_{i_2}+\cdots +d_{i_k}\bolde_{i_k} \end{equation*}
for some positive integers \(i_1< i_2< \dots < i_k\) and scalars \(d_{i_k}\in \R\text{.}\) Letting \(n=i_k\) and setting
\begin{equation*} c_i=\begin{cases} d_{i_j}\amp \text{if } i=i_j \text{ for some } 1\leq j\leq k \\ 0\amp \text{otherwise} \text{,}\end{cases} \end{equation*}
we have
\begin{equation*} s=c_1\bolde_1+c_2\bolde_2+\cdots +c_n\bolde_n\text{.} \end{equation*}
This shows that any linear combination of \(S\) can be expressed in the form \(s=\sum_{i=1}^nc_i\bolde_i\text{,}\) as claimed in the hint. Now since by definition \(\bolde_i\) is the infinite sequence
\begin{align} \bolde_i \amp =(0,0,\dots, 0, \underset{i\text{-th term}}{1},0,\dots)\tag{1.1.9} \end{align}
we have
\begin{equation*} \sum_{i=1}^nc_i\bolde_i=(c_1,c_2,\dots, c_n,0,0,\dots)\text{.} \end{equation*}
This shows that any linear combination of the \(\bolde_i\) is a sequence with only finitely many nonzero terms! In particular the infinite sequence
\begin{align} (1)_{i=1}^\infty \amp =(1,1,\dots)\tag{1.1.10} \end{align}
is not a linear combination of the \(\bolde_i\text{.}\)
