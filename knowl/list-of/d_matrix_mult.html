Definition 3.1.8. Matrix multiplication.

Let \(m,n,r\) be positive integers. Given an \(m\times n\) matrix \(A=[a_{i,j}]_{m\times n}\) and an \(n\times r\) matrix \(B=[b_{i,j}]_{n\times r}\text{,}\) we define their product to be the \(m\times r\) matrix \(AB\) defined as
\begin{equation} AB=\left[\sum_{k=1}^{n}a_{ik}b_{kj}\right]_{m\times r}\text{.}\tag{3.1.1} \end{equation}
Equivalently, using matrix-entry notation, we have
\begin{align} [AB]_{i,j} \amp =\sum_{k=1}^{n}a_{i,j}b_{k,j}\tag{3.1.2} \end{align}
for all \(1\leq i\leq m\) and \(1\leq j\leq r\text{.}\)
🔗
The operation
\begin{align*} M_{mn}\times M_{nr} \amp \rightarrow M_{mr}\\ (A,B) \amp \mapsto AB \end{align*}
is called matrix multiplication.
