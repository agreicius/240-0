Definition 1.1.4. Infinite sequences of real numbers.

Let \(I=\Z_+=\{1,2,\dots\}\text{.}\) A real-valued tuple indexed by \(I\) is called an infinite sequence. We will use any of the following notations for tuples indexed by \(I=\Z_+\text{:}\)
\begin{align*} (a_i)_{i\in I}\amp\amp (a_i)_{i=1}^\infty \amp\amp (a_1,a_2,\dots) \text{.} \end{align*}
Furthermore, the set \(\R^I\) of all infinite sequences is denoted \(\R^\infty\text{:}\) i.e.,
\begin{equation*} \R^\infty=\{(a_i)_{i=1}^\infty\mid a_i\in \R \text{ for all } i\in \Z_+\}\text{.} \end{equation*}
