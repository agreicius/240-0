Theorem 1.1.20. Zero space.

Let \(V\) be a singleton: i.e., \(V\) is a set containing exactly one element. There is a unique choice of operations
\begin{align*} V\times V\amp \rightarrow V \amp \R\times V\amp \rightarrow V \\ (\boldv, \boldw) \amp \mapsto \boldv+\boldw \amp (c,\boldv)\amp \mapsto c\boldv \end{align*}
making \(V\) into a vector space.
🔗
🔗

Proof.

Let \(V=\{\boldu\}\text{.}\) Since
\begin{equation*} V\times V=\{(\boldu,\boldu)\}\text{,} \end{equation*}
to define a vector addition operation
\begin{align*} V\times V \amp \rightarrow V\\ (\boldv,\boldw) \amp \rightarrow \boldv+\boldw\text{,} \end{align*}
we only need to define what \(\boldu+\boldu\) is. Furthermore, since by definition we must have \(\boldu+\boldu\in V=\{\boldu\}\text{,}\) we have no choice here: we must define \(\boldu+\boldu=\boldu\text{!}\)
🔗
Similarly, it is easy to see that there is only one possible scalar multiplication operation, defined as \(c\boldu=\boldu\) for all \(c\in\R\text{.}\) These two operations being so simple, it is now easy to verify that they satisfy all of the algebriac axioms. Furthermore, we have no choice for the zero vector and inverse vectors: we must choose \(\boldzero=\boldu\text{,}\) and \(-\boldu=\boldu\text{.}\) This seems somewhat odd, since \(\boldu\) is its own vector inverse, but it is easy to verify that these choices satisfy Axioms iii and iv:
\begin{align*} \boldzero+\boldu \amp =\boldu+\boldu \amp (\text{def. of } \boldzero)\\ \amp = \boldu \amp (\text{def. of } +)\\ -\boldu+\boldu \amp =\boldu+\boldu \amp (\text{def. of } -\boldu)\\ \amp = \boldu \amp (\text{def. of } +)\\ \amp = \boldzero \amp (\text{def. of } \boldzero)\text{.} \end{align*}
The remaining axioms can be verified in a similar elementary fashion. We leave their verification as an exercise.
