Remark 1.1.3. Real-valued tuples.

Do not be intimidated by the formality of Definition 1.1.1. As you will see, the way we handle general \(I\)-tuples is very similar to how we handle elements of \(\R^2\text{,}\) or \(\R^3\text{,}\) or more generally, \(\R^n\text{.}\)
🔗
To make the jump to this slightly more general setting, it is useful to make the following observation: to specify an element \((a_1,a_2,\dots, a_n)\) of \(\R^n\text{,}\) we must specify its \(i\)-th component \(a_i\) for each index \(i\) of the index set \(\{1,2,\dots, n\}\text{.}\) Thus \(\R^n\) can be thought of as \(\R^I\text{,}\) where \(I\) is a very particular type of index set: namely, \(I=\{1,2,\dots, n\}\text{.}\) The definition for general \(\R^I\) works in exactly the same way. To specify an element of \(\R^I\) we must specify its \(i\)-th component \(a_i\) for each index \(i\) in our index set \(I\text{.}\) The only difference is that instead of the index set \(I\) being of a very particular type (like \(\{1,2,\dots, n\}\)), we allow it to be anything you like, even an infinite set!
