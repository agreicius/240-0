Definition 1.1.9. Tuple equality.

Two real-valued tuples \((a_i)_{i\in I}\) and \((b_j)_{j\in J}\) are equal, denoted \((a_i)_{i\in I}=(b_j)_{j\in J}\) if the following two conditions hold.
  1. \(I=J\text{.}\)
    🔗
    🔗
  2. \(a_i=b_i\) for all \(i\in I\text{.}\)
    🔗
    🔗
In plain English, two tuples are equal if they have the same index set and assign the same values to each element of the index set.
