Corollary 4.4.11. Infinite dimensional spaces.

Let \(V\) be a vector space. If for all integers \(n\) we can find a linearly independent subset \(S\subseteq V\) with \(\abs{S}> n\text{,}\) then \(V\) is infinite dimensional. In other words, if \(V\) contains linearly independent subsets of arbitrarily large cardinality, then \(\dim V=\infty\text{.}\)
🔗
🔗

Proof.
We give a proof by contradiction. Let \(V\) be a vector space satisfying the stated condition: i.e., \(V\) contains linearly independent sets of arbitrarily large cardinality. Suppose by contradiction that \(V\) is finite dimensional. By Definition 4.4.1 this means there is a finite basis \(B\) with \(\abs{B}=n\in \Z\text{.}\) But then by Theorem 4.4.10 any linearly independent set \(S\subseteq V\) must satisfy \(\abs{S}\leq n\text{.}\) This contradictions the assumption that \(V\) contains linearly independent sets of arbitrarily large cardinality. Since we have reached a contradiction, we conclude that \(V\) must be infinite dimensional.
