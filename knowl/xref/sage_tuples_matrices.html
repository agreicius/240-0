Sage Example 1. \(n\)-tuples and matrices.

To create an \(n\)-tuple in Sage, use the vector() command. The input should be a sequence of numbers enclosed in brackets.
🔗
You can make use of sequence routines to create special types of \(n\)-tuples.
🔗
If you prefer the two outputs above to not be listed as a pair, you can use the print() command in sequence. (This is a peculiarity of interactive SageCells, not Sage itself.) Alternatively, use show() for a nicely typeset display of the output.
🔗
Once a vector v is created in Sage, various properties of the vector can be computed using the v.foo() syntax. For example, the command v.length() returns the length of the vector v.
🔗
Matrices are created in Sage using the matrix() command, and are entered as a list of lists, where the \(i\)-th list of this list represents the \(i\)-th row of the matrix, considered as a rectangular array.
🔗
To retrieve entries from \(n\)-tuples or matrices, Sage uses the usual Python list syntax: e.g., v[i] and A[i,j]. As with all things Python, we always count from 0. Thus if A is assigned to a matrix in Sage, A[i,j] is its \((i+1),(j+1)\)-th entry.
🔗
There are also built-in constructors for matrices consisting entirely of zeros, or entirely of ones.
